📌 Desafio em PHP (Cadastro e Login)

Foi proposto o seguinte desafio pelo CEUB: desenvolver uma aplicação web em **PHP** para cadastro e login de usuários. 


🚀 **Tecnologias**

* Linguagem: **PHP 8**
* Servidor: **Apache** (XAMPP)
* Tipo de aplicação: **Aplicação Web**

---

⚙️ **Como Executar**

**Pré-requisitos:**

* Instalar o PHP (versão recomendada: 8)
* Ter um servidor local (XAMPP)

**Passos:**

1. Clonar o repositório:

   ```bash
   git clone https://github.com/SeuUsuario/Sistema-Cadastro-Login-PHP.git
   ```
2. Mover a pasta para o diretório htdocs do XAMPP.
3. Iniciar o servidor Apache.
4. Acessar a aplicação no navegador
